# Code of conduct

Every repository of [DominikSienkiewicz](https://github.com/DominikSienkiewicz) follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies to every space of a project: issues, pull requests, reviews and discussions.

Report unacceptable behaviour privately to the maintainer, through the contact on
[the maintainer's GitHub profile](https://github.com/DominikSienkiewicz), not in a public issue. Reports are read by
the maintainer only and are answered as the Covenant's enforcement guidelines describe.
